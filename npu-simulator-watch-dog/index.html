CANN npu-simulator SLA 口径契约

为什么全指标自算？

CANN 平台旧接口存在 24 小时快照滞后，且频繁面临 24h JWT/Cookie 过期轮换失效问题。本项目直接通过 GitCode CLI + GitCode Open API 现算全量指标，确保实时性与确定性。

核心口径说明：

  • 自然时间口径：计算时长时不剔除周末与法定节假日。时长数字客观反映外部开发者的真实等待时长。
  • 首次响应定义：第一条非创建者且非机器人的评论时间。
  • 关联规则：PR 正文中明确出现 #n 且 n 存在于本仓 Issue 列表。
  • PR 可合并判定：Git 底层可合并且必须同时包含 cann-cla/yes（CLA 签署）与 ci-pipeline-passed（门禁流水线通过）两个标签。
指标合规线达标标准
Issue 闭环率蓝 ≥90%，橙 50%~90%，红 <50%落在蓝区为合规
首次响应达标率蓝 ≥80%，橙 50%~80%，红 <50%落在蓝区为合规
平均首次响应(H)≤ 24h超过 24h 即不达标
未响应 / 孤儿 PR= 0零容忍，>0 即不合规
PR 可合并门禁无冲突 + 必备标签包含 cann-cla/yes 与 ci-pipeline-passed 且 mergeable
